# Comparison session

**Comparison session** is a core application activity of comparing [Item](item.md)s using selected [Comparison Mode](comparison-mode.md).

It stores configurations, progress and results.

The session metadata includes:
- Start date (mandatory date)
- End date (optional date)
- Selected [Comparison Mode](comparison-mode.md)
- [Comparison question](comparison-question.md)
- Custom params of comparison mode
- Selections made during comparisons
