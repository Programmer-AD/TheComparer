# Comparison page

Primary application page.

Contains:
- "Back" button - navigates to [Home Page](home-page.md)
- [Comparison question](../../glossary/comparison-question.md) in header
- Progress estimation (progress bar + number of comparisons)
- Compare area:
    - 2 clickable [Item](../../glossary/item.md) displays
    - "Equal" button in the middle (could be disabled for some modes)

Once all comparisons are done - navigates to the [Comparison result page](comparison-result-page.md).
