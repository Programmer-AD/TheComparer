# Pack management page

A page to manage [Item Pack](../../glossary/item-pack.md) content.

Contains:
- Header
- "Back" button - navigates to the [Home Page](home-page.md)
- Grid with [Item](../../glossary/item.md) entries
    - Header has:
        - Add item button - opens inline form
    - Click on row opens inline edit form
    - Rows have "Delete" button
