# Comparison start page

A page that helps to setup your [Comparison session](../../glossary/comparison-session.md).

It contains:
- "Back" button - navigates to [Home Page](home-page.md)
- Header "Start comparison"
- Fields:
    - [Comparison Mode](../../glossary/comparison-mode.md) selector
    - Mode description (long text)
    - Question selector (from pack or custom input)
    - Params for selected mode if any (fields)
- "Start" button - navigates to [Comparison page](comparison-page.md)
